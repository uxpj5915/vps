## 买海外 VPS 之前，先看清三个最容易踩的坑

第一坑是续费价。很多商家靠首年低价获客，续费翻倍。市面上有 VPS 汇总站专门提醒过这类情况：比如 Racknerd 部分促销机首年 $10，续费可能到 $20 以上。搬瓦工在这方面是少数让人省心的——套餐是循环计费，年付到期后续费还是当初的价格，叠加循环优惠码还能继续用，不存在“首年便宜第二年涨价”的结构。这一点对打算长期持有的用户影响很大：算成本要按第二、三年的续费价算，别只看首年。

第二坑是线路。同样是“美国洛杉矶”，普通线路和 CN2 GIA 的晚高峰体验差距很大。CN2 是中国电信的下一代承载网，其中 GIA（Global Internet Access）是精品档，带宽贵、容量有限；官方口径是晚高峰普通线路丢包率可达 30% 以上，而 CN2 GIA 适合网页服务、VOIP、在线会议这类对稳定性敏感的用途。洛杉矶 USCA_9 机房还同时打通了电信 CN2 GIA、移动 CMIN2 和联通精品网三家的回程，这就是同配置套餐价差能到好几倍的原因——差价主要在线路，不在 CPU 和内存。

第三坑是退款条款。不少商家写着“30 天无理由”，实际执行时一堆限制，这个后面单独开一节讲。

## 30 天退款：能退，但条件比宣传语严格

搬瓦工确实提供 30 天退款，新订单在下单后 30 天内可以申请，退款原路返回（支付宝买的退回支付宝）。但条款里藏了几个细节，中招任何一个就退不了：

- 流量门槛：当月流量使用量必须**低于月配额的 10%**
- IP 状态：分配的 IP 不能进黑名单，也不能因为黑名单问题换过 IP
- 支付记录：账户不能有 PayPal 争议或信用卡拒付记录
- 账户限制：账户下服务总数（含已取消的）不超过 3 个
- 退款后果：所有数据、快照、备份立即删除且不可恢复；退款后账户还能继续买，但永不再享有退款资格

还有一个操作层面的坑：**千万别用发起 PayPal 争议的方式要退款**。官方条款写明，发起争议会立即暂停你名下所有服务，而且商家可以按每小时 $40、以 15 分钟为一个计费时段收取处理费，付清前不恢复服务。正确流程是提交工单说明退款原因并确认数据已备份，收到自动回复后回复确认即可。老账户新买的 VPS 也能退，判断依据是当前订单是否为新购且在 30 天内，账号注册时间不是门槛。
